# OverTheWire — Bandit Writeup

Writeup personnel du wargame **Bandit** d'OverTheWire (niveaux 0 → 33).

## ⚠️ Avertissement

Ce dépôt ne contient **aucun mot de passe**, **aucune clé privée**, **aucune solution copiable**.
Il respecte la règle OverTheWire : pas de spoilers. Seuls les **concepts**, **syntaxes** et **pièges** sont documentés.

## Objectif

Documenter ma progression et les compétences acquises :
- bases du shell Linux
- clés SSH et permissions
- réseau (TCP, TLS, scan de ports)
- cron, setuid, scripts
- évasion de shells restreints
- git (clone, branches, tags, historique, push)
